# Bohanes Technologies – firemní web

První pracovní verze firemního webu Bohanes Technologies.

## Hlavní produkt
Lázeňský Commander.

## Obsah
- firemní značka Bohanes Technologies,
- produktový hero a veřejně komunikovatelné funkce Commanderu,
- přínosy pro klienta,
- pilotní model pro lázně,
- připravená místa pro instalační a aktivační QR kód,
- kontaktní formulář bez ostrého odesílání,
- responzivní zobrazení.

## Stav
Pracovní preview před pořízením firemní domény. Stránka má meta robots noindex/nofollow.

## Důležité
QR kódy a skutečný kontaktní e-mail se nesmí doplnit odhadem. Doplní se až po existenci definitivních distribučních a firemních adres.
