# Lázeňský Commander — schválený vizuální zdroj pravdy (24. 9. 2026)

Jedinou schválenou referencí je uživatelem potvrzená infografika
„Barevná paleta – přehled kontrastních barev“. Bez nového výslovného
schválení se nemění barva, ikona ani přiřazení kategorie.

| Skupina | Barva | Ikona |

| Jídlo | #50B863 | fork.knife |
| Vodoléčba | #2ED4FF | drop |
| Rehabilitace | #2EE6C4 | figure.run |
| Masáže | #FF7A59 | leaf.fill |
| Zábaly / teplo | #FFC857 | custom: tři stoupající vlny + spodní vodorovná čára |
| Elektroléčba | #D6B4FE | atom |
| Terapie / fallback | #FF5DA8 | cross.case.fill |
| Konec procedur | #94A3B8 | clock.fill |

Souhrnné karty používají stejný systém: Terapie růžová, Konec procedur
neutrální, Volno do večeře azurové, Večeře zelená.

Standardní kruhový badge má v celé aplikaci 50 pt. Jedinou výjimkou jsou
hlavní a následující událost v „Co mě teď čeká“, kde může mít 59 pt.
